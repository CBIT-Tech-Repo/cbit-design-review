# CBIT website: design review copy

The v4 design mockups (30 September 2026) published at https://staging.cbitx.com so the CBIT team can review them.

- Static HTML, no build step. Every page carries a noindex tag, and robots.txt asks search engines to stay out.
- **Not the real site.** The real site is built from the `cbit-website` repository.
- **Not private.** GitHub Pages on the free plan cannot be password-protected. The copy includes review notes and items still waiting for clearance (photos, consents), so it is for the CBIT team only and is removed or replaced as items are cleared.
- Deleting this repository removes the copy and its history.
